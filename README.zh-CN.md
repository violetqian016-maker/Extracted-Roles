# Extracted Roles — 本科研究数据集

这是 **Ruiyi（Violet）Qian 在复旦大学本科研究期间构建的角色对话数据集**，用于研究角色语言特征与大语言模型的角色扮演生成。项目将影视台词整理为可分析、可用于实验的结构化资源，包含 **16 部作品、96 份角色台词文件、550,628 条台词和 174,000 对提问与回复**，并配有角色档案及词汇表。

[English](README.md) · [数据结构](docs/DATASET.md) · [已知问题](docs/KNOWN_ISSUES.md)

## 我的研究贡献

- **清洗并标准化角色台词。** 处理 55 万余条台词，进行文本规范化、说话人名称映射，并移除非对话内容及编码噪声。
- **构建角色对话样本。** 基于相邻对话轮次构建 174,000 对提问与回复，结合去重、质量过滤和角色级数量平衡，将台词转化为结构化的生成实验数据。
- **检查数据质量与可追溯性。** 在构建过程中检查样本完整性、说话人一致性及来源记录；发布数据保留样本 ID、说话人信息、来源引用及质量标记，便于进一步检查和筛选。
- **开展角色扮演生成评估。** 使用自动指标和基于大模型的成对比较，评估基线与动态词汇增强设置。个人项目总结记录：增强设置在 **479 次有效比较中取得 64.5% 胜率**。

以上方法和评测数字依据个人项目总结；当前仓库可以直接核验数据规模。论文全文、原始实验输出及完整构建程序尚未收录，因此该仓库目前无法独立复现上述胜率。详见 [研究背景与依据](docs/RESEARCH.md)。

## 数据集的研究意义

角色扮演研究需要同时考察角色的身份背景与实际语言表达。这份数据集将相关资源组织为四个互补层次：

| 数据资源 | 可支持的研究 |
| --- | --- |
| 角色台词 | 分析惯用表达、词汇偏好，以及不同角色之间的语言差异 |
| 提问与回复对 | 为给定对话输入生成目标角色回复的实验提供样本 |
| 角色词汇表 | 为词汇条件控制提供候选词语与短语，支持本科项目中探索的动态词汇增强思路 |
| 角色档案 | 提供身份与背景描述，可与台词中的语言证据结合研究；事实内容仍需核实 |

对话样本还保留来源及质量元数据，便于研究者检查样本并按实验需求过滤。16 部作品的覆盖范围支持同一作品内的角色比较，也允许探索跨作品差异。当前发布提供这些实验所需的数据资源，尚不能据此声称已证明跨作品泛化能力；跨层角色对齐和防止数据泄漏的评测划分仍需专门准备。

## 本地使用

需要 Git 和 Python 3.10 及以上版本，无需安装第三方 Python 依赖。

```bash
git clone https://github.com/violetqian016-maker/Extracted-Roles.git
cd Extracted-Roles
python3 scripts/dataset.py validate
python3 scripts/dataset.py catalog --check
python3 -m unittest discover -s tests -v
```

原始数据目录及文件名保持不变。不同目录的作品名和角色名不完全一致，不能仅凭字符串直接关联。`docs/catalog.json` 提供全部文件的路径、条数、大小和 SHA-256 摘要。

## 校验范围

工具检查 JSON 格式、主要字段类型、对话是否为两轮、文本是否为空、目标角色与文件名是否一致、字数总和，以及跨文件对话 ID 是否重复。GitHub Actions 自动运行回归测试和目录索引检查。

格式通过不代表台词归属、剧情事实和上下文已经人工核实。部分保留样本带有短句或恢复标记；源脚本路径虽出现在数据中，对应源文件和提取程序并未收录。
