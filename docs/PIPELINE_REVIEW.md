# 数据构建流程评审

## 结论

论文的双输出设计值得保留：角色台词为词汇分析提供证据，提问与回复对为对话监督提供样本。当前优先需要改进的是数据身份管理、筛选决策的可解释性和实验复现条件。

这次检查基于已发布文件、论文方法和现有校验工具。原始提取程序、源剧本和实验日志尚未收录，因此不能据此判断原程序的运行效率，也无法直接验证所有样本是否跨越场景边界。

## 本次实际检查

完整机器报告见 [audit.json](audit.json)，可在仓库根目录重跑：

```bash
python3 scripts/audit_dataset.py --output docs/audit.json
```

脚本只读源数据。短句、重复和恢复标记均作为复核信号，不会触发自动删除。

| 检查项 | 当前文件结果 | 应如何理解 |
| --- | ---: | --- |
| 对话样本 | 174,000 | 与论文总数一致 |
| 每角色样本数 | 1,083–2,000；中位数 1,900 | 论文最小值为 1,025，需追溯版本 |
| 同作品、同目标角色的重复文本组 | 139 组；每组 2 条 | ID 唯一不等于文本唯一；可能包含真实重复表达或重复抽取 |
| 提问与回复文本相同 | 88 对 | 可能是真实复述，需结合原始上下文判断 |
| 提问少于 3 个存储词数 | 9,954 对 | 不自动判为低质；简短问题也可构成有效触发 |
| 回复少于 3 个存储词数 | 49 对 | 与论文表 8 的 14 条不同，需核对版本和计数规则 |
| 回复超过 50 个存储词数 | 4,075 对 | 与论文表 8 的 4,460 条不同 |

重复定义为：作品目录、目标角色、提问文本、回复文本一致；文本仅做大小写折叠及空白压缩，保留标点。不跨角色合并，不检测近重复。长度检查使用 JSON 内的存储词数，不重新分词；论文的词数计算规则尚不完整。

## 优先级 1：让数据对应关系和版本可以核对

**建立角色清单。** 为每个角色分配稳定的 `character_id`，记录规范名称、别名、作品 ID，以及四类资源的相对路径。对不确定映射标记待核实，避免通过模糊匹配自动合并同名人物。`Bones_Jack.json` 应在清单中标为不可用，复核其与 `Bones_Hodgins.json` 的关系后再决定归档或删除。

**固定发布版本。** 保留论文时点的统计与当前发布统计，增加变更记录和发布摘要。台词相差 27 行、最小角色样本数及长短回复数量不同，都需要回到原始脚本和历史输出核查，不能仅为匹配论文而修改文件。

**拆分质量标记与保留理由。** 建议分别记录最初触发的检查、最终决定、恢复方法和规则版本。这样能够区分“正常通过”“低资源角色恢复”和“待复核”，也便于分析不同策略带来的样本数量和质量变化。

## 优先级 2：提高训练和评测的可信度

**在角色平衡之前检查文本重复。** 给规范化文本生成指纹，对同角色重复组保留全部来源与出现次数。区分真实复现的台词和重复抽取后，再决定训练权重或合并策略。当前的 139 组只是精确规范化重复；近重复检查可作为后续步骤。文本相同的组应保持在同一评测划分中。

**保留场景边界后构造相邻轮次。** 当前来源引用有行号、CSV 行号、恢复上下文和合并记录等多种结构。下一版应统一为来源、剧集、场景、轮次、说话人和清洗前后文本的可追踪记录。原始字段允许时，仅在同一场景内配对；缺少场景信息时显式标记不确定，不能把行号相邻直接当作语义连续。

**先划分来源，再提取实验词表。** 当前发布没有训练、验证、测试划分。建议按剧集或场景分组，并结合重复组约束划分，防止相邻或重复台词落入不同集合。用于实验的词表只从训练部分提取；已经发布的全量词表可以保留为语料分析资源，不能默认用于干净的留出评测。如果原始源文件是一整部作品，仍需恢复更细的边界，不能把每个大文件简单当作唯一分组。

去重与训练测试重叠的关系有已有研究依据：[Lee et al., 2022](https://aclanthology.org/2022.acl-long.577/)。这里提出的具体划分方案是针对本项目来源结构的建议，并非该论文验证过的本项目实验结果。

## 优先级 3：让分析结果更有解释力

**用抽样复核补足结构检查。** 按作品、角色、七种来源类型，以及恢复方法分层抽样，人工检查说话人归属、对话衔接和残留噪声。报告每层复核数量、错误类型与比例，避免用“字段不为空”代替“内容正确”。短句和恢复样本应单列分析。

**检查词汇是否真的具有区分度。** 82.92% 的词表命中率说明有词汇覆盖，不直接说明这些表达能区分角色。可以加入频率相近的非目标角色词表作对照，在留出文本上比较目标词表、其他角色词表和通用词表的覆盖表现。词表提取规则、短语边界和重叠计数方法应固定后再比较。

**记录平衡策略的代价。** 保留现有每角色上限设计，并比较平衡前后的角色覆盖、被移除的高质量样本和词汇多样性。台词层与训练种子层继续使用不同目标，避免为了等量而损失可供词汇研究使用的原始表达。

**补齐评估记录。** 保存模型与配置、动态词表构建方式、评测输入、随机设置、评分提示和逐条结果。成对评分随机交换展示顺序并隐藏设置名称；报告全部有效比较及排除平局的两个分母。将词汇对齐、上下文相关性、角色一致性和多样性分别解释，再用人工复核检验大模型评分的可靠性。479 条有效比较中 309 次获胜应继续作为特定设置下的初步结果呈现。

## 实施顺序与本次范围

建议顺序为：角色清单与版本核对 → 统一来源及筛选决策 → 重复复核与场景约束 → 划分数据并重新提取训练词表 → 补齐原始程序与评估记录。

本次已经补充了只读质量画像工具及审计结果，并据此整理优化建议。原始样本、角色档案、词汇表及实验结论均未自动更改。缺少原始材料的部分仍为后续工作，不能作为已完成的项目成果写入简历。
